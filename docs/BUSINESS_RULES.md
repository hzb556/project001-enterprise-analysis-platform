# 业务规则手册

> **用途**：定义所有业务计算逻辑、阈值、分类标准。AI 开发和人工验证的统一参考。
> **维护**：业务规则变更时必须同步更新此文档。

---

## 一、客户状态定义

### 时间窗口

| 概念 | 定义 | 用途 |
|------|------|------|
| **近 3 月** | 数据集中最近的 3 个年月（如 `2025-10 ~ 2025-12`） | 判断活跃/沉睡 |
| **近 6 月** | 数据集中最近的 6 个年月（如 `2025-07 ~ 2025-12`） | 判断流失 |

### 客户状态分类

| 状态 | 判断规则 | 业务含义 |
|------|---------|---------|
| **活跃** | 近 3 个月有交易记录 | 正常客户 |
| **沉睡** | 近 6 个月有交易，但近 3 个月无交易 | 早期预警，挽回成本低 |
| **流失** | 近 6 个月无任何交易记录 | 实质性流失 |

### 新增客户

```
新增客户 = 当年有交易记录 - 上年有交易记录
```

即：去年完全没交易的客户，今年开始交易。

## 二、KPI 计算口径

### 收入相关

| 指标 | 计算公式 |
|------|---------|
| **当期收入** | `SUM(amount) WHERE year = 当前年 AND month ≤ 最新月` |
| **同比收入** | 与上一年相同月份范围对比 |
| **同比增长率** | `(当期收入 / 同期收入 - 1) × 100%`，同期收入=0 时返回 null |
| **CAGR** | `((末年收入 / 首年收入) ^ (1/年数) - 1) × 100%`，至少需要 2 年数据 |

### 毛利相关

| 指标 | 计算公式 |
|------|---------|
| **毛利额** | `SUM(amount) - SUM(cost)` |
| **毛利率** | `(收入 - 成本) / 收入 × 100%`，收入为 0 时返回 0 |
| **毛利率同比** | `当期毛利率 - 上年同期毛利率`（差值，单位：百分点） |

### 客户相关

| 指标 | 计算公式 |
|------|---------|
| **成交客户数** | `COUNT(DISTINCT customer) WHERE year = 当前年` |
| **新增客户数** | 见上文「新增客户」定义 |
| **客单价** | `当期收入 / 当期订单数` |
| **人均收入** | `当期收入 / 当期客户数`（业务员页签用） |

## 三、客户分层（ABC 分析）

### 帕累托分层规则

| 层级 | 累计客户占比 | 典型收入占比 | 管理策略 |
|------|-------------|-------------|---------|
| **A 级** | 前 20% 客户 | ~70% | 专属销售经理，定期拜访 |
| **B 级** | 20% ~ 50% 客户 | ~25% | 标准维护，季度回访 |
| **C 级** | 后 50% 客户 | ~5% | 批量自动化维护 |

### 计算步骤

1. 按收入降序排列所有客户
2. 计算每个客户的累计收入占比
3. 按累计客户数占比分区：≤20% → A，20%~50% → B，>50% → C

## 四、异常检测规则

### 环比异常

| 条件 | 标记 |
|------|------|
| 当月收入环比变化 > +30% | 🔴 异常增长（可能是大单或数据错误） |
| 当月收入环比变化 < -30% | 🔴 异常下降（可能是客户流失或淡季） |

### 集中度风险

| Top3 客户收入占比 | 风险等级 |
|------------------|---------|
| > 50% | ⚠️ 高风险（高度依赖大客户） |
| 30% ~ 50% | 需关注 |
| < 30% | 健康 |

### IQR 离群值（大额异常交易）

使用四分位距法：`Q3 + 3 × IQR` 以上的交易被标记为离群值。

## 五、时间范围规则

| 场景 | 规则 |
|------|------|
| 同比计算 | 当年 1 月至最新月份，与上一年同期比较（不是全年比较） |
| 月度趋势图 | 默认显示全部月份（智能窗口 24 个月，超出可滚动） |
| 费用分析窗口 | 默认 24 个月（数据不足时显示全部） |
| 异常检测 | 基于全部可用月份 |
| 年度对比 | 基于数据集中所有年份 |

## 六、数据过滤规则

### 数据清洗（processor.py 自动执行）

| 规则 | 处理方式 |
|------|---------|
| 年份不在 2000~2100 | 删除该行 |
| 月份不在 1~12 | 删除该行 |
| 金额为空 | 填充为 0 |
| 客户/产品为空 | 填充为「未知」 |
| 重复记录 | 按 `order_no + year + month + amount` 去重（保留第一条） |
| 负数金额 | 保留（可能是退货） |

### 货币/单位

- 原始数据：人民币元
- 图表显示：万元（÷10000）
- 毛利率：百分比数值（21.9 表示 21.9%）
- 小数精度：收入保留 1 位小数，毛利率保留 1 位小数

## 七、桑基图流转规则

### 节点定义

| 节点 | 含义 |
|------|------|
| 上年活跃 | 上一年度有任何交易记录的客户 |
| 当年新增 | 当年有交易但上年无交易的客户 |
| 当年活跃 | 近 3 个月有交易 |
| 当年沉睡 | 近 6 月有但近 3 月无交易 |
| 当年流失 | 近 6 月无交易 |

### 流转链路

```
上年活跃 → 当年活跃  （留存活跃）
上年活跃 → 当年沉睡  （老客户进入沉睡）
上年活跃 → 当年流失  （老客户流失）
当年新增 → 当年活跃  （新客户活跃）
当年新增 → 当年沉睡  （新客户已沉睡，质量差）
当年新增 → 当年流失  （新客户已流失，质量极差）
```

### 三端同源原则

KPI 卡片 ←→ 桑基图 ←→ 明细表（新增/沉睡/流失列表）必须使用完全相同的定义和计算逻辑。

## 八、毛利率监控规则

| 场景 | 规则 |
|------|------|
| 毛利率同比下降 > 3 个百分点 | 诊断结论中标记为「需关注」 |
| 毛利率同比下降 > 5 个百分点 | 显著下降，建议检查定价策略 |
| 毛利率 < 0 | 亏本销售，需排查是定价错误还是清仓处理 |
| 自有品牌 vs OEM | 自有品牌毛利率应显著高于 OEM（如 40%+ vs 20%） |

## 九、数据导出规则

| 格式 | 内容 | 文件命名 |
|------|------|---------|
| HTML | 完整看板页面（与在线版 100% 一致） | `{报告名}_{日期}.html` |
| CSV | 明细数据（UTF-8 BOM） | `{报告名}_{日期}.csv` |
| Excel | 明细数据 + KPI 汇总（2 个 Sheet） | `{报告名}_{日期}.xlsx` |

导出文件名仅含 ASCII 字符（中文会被过滤，避免浏览器下载乱码）。
