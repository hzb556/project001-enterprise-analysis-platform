# 产品概述

> **面向读者**：产品负责人、管理层、新成员入职
> **最后更新**：2026-07-16

---

## 一、产品定位

**企业运营分析平台** 是一款面向中小企业的 **自助式商业智能（BI）工具**。

**一句话描述**：用户上传 Excel 财务/销售数据 → 系统自动生成包含图表、诊断结论、明细表的完整分析报告。

**核心价值**：把「需要 Excel 高手 + 财务背景 + 一整天时间」的数据分析工作，变成「上传文件 → 3 分钟出报告」。

---

## 二、目标用户

| 用户角色 | 使用场景 | 核心需求 |
|---------|---------|---------|
| **企业老板/总经理** | 月度经营会议前查看 KPI 仪表盘 | 一眼看清收入趋势、毛利变化、客户流失情况 |
| **财务/销售分析人员** | 月度/季度做分析报告 | 快速生成图表和文字结论，减少手工 Excel 操作 |
| **销售经理** | 管理业务员和客户 | 看业务员排名、客户分层、流失预警 |
| **系统管理员** | 管理用户账号和权限 | 开通/停用账号、分配模块权限 |

## 三、功能模块

### 模块 A：费用分析

**解决的问题**：企业钱花哪了？花得对不对？

| 功能 | 说明 |
|------|------|
| 📊 KPI 仪表盘 | 总费用、同比/环比变化、科目占比 |
| 📈 趋势图表 | 年度对比柱状图、月度趋势折线图（支持 24 个月智能窗口） |
| 🔥 热力图 | 部门×科目交叉分析，一眼看出「哪个部门花哪种钱最多」 |
| ☀️ 旭日图 | 科目层级结构，支持双向钻取 |
| 🚨 异常检测 | 自动标记环比波动 >30% 的异常月份 |
| 📋 诊断结论 | 自动生成结构化文字报告（含建议） |
| 📥 导出 | HTML/Excel/CSV 三种格式 |

### 模块 B：销售分析

**解决的问题**：收入从哪来？客户买什么？谁在流失？

#### 8 个分析视角

| 页签 | 回答什么问题 | 核心图表 |
|------|-------------|---------|
| **总览** | 整体收入/毛利/客户情况怎么样？ | KPI卡片 + 年度堆叠柱 + 月度双线 + 双向旭日图 + 诊断结论 |
| **客户** | 谁是核心客户？谁在流失？ | Top10柱状 + 气泡图 + 排名变化 + 帕累托 + 桑基流转 + 明细 |
| **产品** | 哪些产品贡献最大？毛利怎么样？ | Top10柱状 + 气泡图 + 排名变化 + 旭日图 + 生命周期 |
| **品类** | 钛杯/钢杯/塑料杯/配件各占多少？结构在变吗？ | 柱状+饼图 + 月度趋势 + 结构对比 + 明细下钻 |
| **部门** | 营销中心 vs 品牌中心，哪个部门表现好？ | KPI对比 + 月度趋势 + 客户Top10 + 客户占比 + 明细下钻 |
| **业务员** | 15个业务员谁做得好？谁在吃大锅饭？ | 收入排行 + 散点图 + KPI聚合 + 明细下钻 |
| **品牌** | 自有品牌 vs OEM，谁的利润高？ | 柱状+饼图 + 月度趋势 + 毛利率对比 + 明细下钻 |
| **明细** | 我要查具体某笔交易 | 可搜索/筛选/分页/导出的原始数据表 |

#### 核心分析能力

- **客户分层（ABC）**：A类（前20%客户）贡献70%收入 → 配专属销售；C类 → 批量维护
- **流失预警**：自动识别「沉睡客户」（3个月无交易）和「流失客户」（6个月无交易）
- **新增客户追踪**：今年新开发的客户质量如何？有多少进入了沉睡？
- **毛利率监控**：哪个品类/产品/客户在「以价换量」？毛利率异常下降？
- **排名变化**：客户/产品排名年度变化 ▲▼，快速发现黑马和下滑者

### 模块 C：用户与安全系统

- 邮箱注册/登录
- 套餐分级：免费试用 / 基础版 / 专业版 / 内部全功能
- **RBAC 三级角色**：admin（全部权限）/ manager（查看所有报告、导出）/ user（自己的报告）
- **模块权限**：可控制用户能访问费用分析还是销售分析
- **审计日志**：自动记录登录/登出/改密/用户管理/报告操作等 8 种事件，敏感信息自动脱敏
- **CSRF 防护**：HMAC-SHA256 token 绑定 session，全局拦截状态修改请求
- **Session 安全**：HttpOnly Cookie + SameSite Lax + 8h 有效期 + 生产 HTTPS only
- **强制改密**：生产环境自动生成管理员密码，首次登录强制修改
- 报告保存：用户的分析结果保存在账号下，可随时回看
- 管理后台：管理员查看所有用户、修改套餐/角色/权限

## 四、产品特点

1. **零门槛**：不需要 SQL、不需要 Python、不需要 BI 工具经验，会传 Excel 就能用
2. **秒级分析**：上传后 3 秒内出图表（58,000 行数据实测）
3. **深度诊断**：不只是画图，还会自动生成文字结论（如「毛利率下降 3 个点，需关注定价策略」）
4. **私有化部署**：数据留在企业自己的服务器上，不外传
5. **企业级安全**：RBAC 三级权限 + 审计追踪 + CSRF 防护 + Session 加固，满足企业安全合规要求
6. **完整闭环**：从 KPI 大盘 → 发现问题 → 下钻定位 → 导出报告，一个平台搞定

## 七、技术概况（产品负责人版）

| 问题 | 答案 |
|------|------|
| 用什么语言写的？ | Python（后端）+ HTML/JavaScript（前端） |
| 数据存在哪？ | SQLite 数据库文件（app.db），可升级到 PostgreSQL |
| 怎么部署？ | Docker 一键部署，或手动安装 Python 后启动 |
| 依赖外部服务吗？ | 不依赖。完全在自己服务器上运行 |
| 支持多少人同时用？ | SQLite 模式下建议 50 人以内，超后可升级数据库 |
| 有 App 吗？ | 目前只有网页版，手机浏览器可以访问（未做适配） |
