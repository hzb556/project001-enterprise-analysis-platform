## 数据流

```
应收单明细表(58,654行)
    │
    ├─→ 总览页     ← 按月/年/品类聚合
    ├─→ 客户分析   ← 按客户聚合，关联同比
    ├─→ 产品分析   ← 按物料/品类/品牌三级可钻取
    ├─→ 部门对比   ← 营销中心 vs 品牌中心
    ├─→ 品类分析   ← 钛杯/钢杯/塑料杯/配件
    ├─→ 业务员分析 ← 15人排行 + 散点图
    ├─→ 品牌分析   ← OEM/天沏/十八藏
    ├─→ 明细表     ← 原始行，可搜索筛选导出
    └─→ 诊断报告   ← 嵌入总览页底部
```
