## 各层分析逻辑与商业价值

### Layer 1: KPI 总览 — "一眼看清客户大盘"

| 指标 | 计算逻辑 | 商业价值 |
|------|---------|---------|
| 成交客户 | `D.kpi.customers`：当年有交易的唯一客户数 | 判断客户基本盘规模 |
| 新增客户 | `D.newCustomers.length`：今年有交易 - 去年有交易 | 衡量获客能力，增长引擎 |
| 流失·6月 | `D.lostCustomers.length`：近6个月无交易 | 预警收入流失风险 |
| 沉睡·3月 | `D.churnRisk.length`：近6月有但近3月无交易 | 早期预警，挽回成本低 |
| 集中度 | Top3 客户收入 ÷ 总收入 | >50%=高度依赖大客户风险 |

**设计原则**: 新增/流失/沉睡 与桑基图**同一口径**（全部客户、同一时间窗口），KPI 总数 = 桑基图流出汇总。

### Layer 2: 筛选控件

- **年份选择器**: 驱动所有图表和表格的年份筛选
- **排序选择器**: 收入排序 / 同比排序 / 毛利率排序
- **搜索框**: 实时过滤客户列表

### Layer 3: 趋势+结构 — "看清谁在增长、谁在下滑"

| 图表 | 分析逻辑 | 价值点 |
|------|---------|--------|
| **Top10 柱状图** | 当年收入排序 + 同比%标签 + 均值参考线 | 一眼识别头部客户增长/下滑 |
| **收入vs毛利率气泡** | X轴=收入，Y轴=毛利率，气泡大小=毛利额 | 找到"高收入低毛利"的异常客户（量大不赚钱） |

**决策场景**: 哪个大客户收入大涨/大跌？哪个客户量大但毛利低需要重新谈判？

### Layer 4: 排名变化 — "谁上来了，谁下去了"

| 指标 | 计算逻辑 | 价值点 |
|------|---------|--------|
| 排名变化 ▲▼ | 今年排名 - 去年排名（从 R 实时计算），红涨绿跌 | 发现快速崛起的客户（重点维护）和快速下滑的客户（及时干预） |
| 新入榜 | 去年无排名，今年进入 Top20 | 潜在黑马客户 |

**决策场景**: 销售会上直接看——"这3个客户排名掉了5名以上，本周去拜访"。

### Layer 5: 客户分层 — "谁是A类、谁是C类"

| 图表 | 分析逻辑 | 价值点 |
|------|---------|--------|
| **帕累托图** | 按收入降序排列，累计占比 70%=A级、95%=B级、其余=C级 | ABC 分层是销售资源配置的基础（A类重点维护、C类评估是否放弃） |
| **树状图** | 面积=收入大小，可按部门筛选 | 直观看到每个部门的大客户是谁 |

**决策场景**: A类客户（前20%）贡献70%收入 → 配专属销售经理。C类客户 → 批量自动化维护。

### Layer 6: 客户流转 + 下钻

#### 6a. 桑基图 — "客户从哪里来、到哪里去"

| 流转链路 | 计算逻辑 | 含义 |
|---------|---------|------|
| 上年活跃 → 当年活跃 | `py_active ∩ cy_active` | 留存客户（活跃） |
| 上年活跃 → 当年沉睡 | `py_active ∩ cy_dormant` | 上年老客户进入沉睡 |
| 上年活跃 → 当年流失 | `py_active ∩ cy_lost` | 上年老客户流失 |
| 当年新增 → 当年活跃 | `new_custs ∩ cy_active` | 新客户且活跃 |
| 当年新增 → 当年沉睡 | `new_custs ∩ cy_dormant` | 新客户但进入沉睡 |
| 当年新增 → 当年流失 | `new_custs ∩ cy_lost` | 新客户已流失（质量差） |

**时间窗口定义**:
- `近3月`: 最近3个年月（如 2025-10 ~ 2025-12）
- `近6月`: 最近6个年月（如 2025-07 ~ 2025-12）
- `py_active`: 去年有交易的客户
- `new_custs`: 今年有交易 - 去年有交易

**数据范围**: 全部客户（`df['customer'].unique()`）

#### 6b. 明细表 — 桑基图下方三列

| 列 | 数据源 | 内容 |
|----|--------|------|
| 🆕 新增客户 | `D.newCustomers` | 客户名、收入(万)、最后交易月 |
| 💤 沉睡客户 | `D.churnRisk` | 客户名、金额(万)、最后交易月 |
| 📉 流失客户 | `D.lostCustomers` | 客户名、累计收入(万)、最后交易月 |

**设计原则**: 与 KPI、桑基图**三端同源**，数量完全一致。

#### 6c. 客户列表 + 下钻

| 功能 | 逻辑 | 价值点 |
|------|------|--------|
| **客户列表** | ABC等级、活跃/沉睡/流失状态、同比%、毛利率、销售贡献% | 完整的客户健康度一览表 |
| **产品构成下钻** | 从 R 实时计算该客户全部产品采购明细（金额+占比） | 了解采购结构，发现交叉销售机会 |
| **月度趋势下钻** | `D.custMonthly` 该客户的月度收入曲线 | 识别采购周期和淡旺季 |

## 核心设计原则

### 1. 三端同源
```
KPI 卡片 ←→ 桑基图 ←→ 明细表
    ↕          ↕         ↕
  同一数据源 (Python processor)、同一计算逻辑、同一客户范围
```

### 2. 数据分层
- **D 数据** (Python processor 预处理): 汇总指标、图表数据、KPI
- **R 数据** (明细行，按需加载): 下钻明细、排名变化、产品构成

### 3. 字段名规范
| 数据源 | 年份字段 | 客户字段 | 金额字段 |
|--------|---------|---------|---------|
| D 数据 | `year`, `cy` | `name` | `revenue`, `amt` |
| R 明细行 | `y` (不是 `year`!) | `customer` | `amt` |

### 4. 时间窗口统一
- 所有"活跃/沉睡/流失"判断使用同一套时间窗口（近3月/近6月）
- KPI、桑基图、明细表使用完全相同的定义

### 5. 分析闭环
```
KPI大盘 → 发现问题
  ↓
Top10+排名变化 → 定位是谁
  ↓
帕累托+树状图 → 分层确认
  ↓
桑基图+明细 → 流转分析
  ↓
客户下钻 → 深度诊断
```
从宏观到微观，从数字到名单，从问题发现到可执行动作。

# 品类页签 — 分析逻辑与价值点

> 版本: v1 | 日期: 2026-07-14 | 与产品页签同构，但品类少(5类)故用「柱状+饼图」替代 TopN

## 结构(筛选→KPI→图表→列表下钻)

1. **年份筛选** catYearFilter — 联动全部图表与KPI
2. **KPI 卡片**(按选中年份): 各品类 收入 / 毛利率 / 占比。数据源 catRevenue[yi] + catGPMargin[yi]
3. **品类收入对比柱状**(含同比%标注) + **品类收入占比饼图**(<5%隐藏标签与引导线)
4. **品类月度趋势**(5条折线) + **结构变化**(两年对比双柱)
5. **品类明细表 + 下钻**: 点品类展开「单品构成(从R明细按 r.cat 聚合) + 月度趋势(catMonthly)」

## 关键实现
- 后端 cat_gp_margin 由单值改为**按年数组**(对齐 all_years)，同 dept 处理
- 同比、下钻数据全部前端从 catRevenue/catMonthly/R 计算，后端仅改毛利率
- 明细行品类字段 r.cat(注意不是 r.category)

## 分析价值
- 品类是杯具业务核心维度(钛杯/钢杯/塑料杯/配件)，看结构演变即看产品战略
- 毛利率按年 → 发现哪个品类在「以价换量」(如塑料杯毛利率 21.9%→10.8% 骤降)
- 下钻单品构成 → 定位品类内是哪个单品在拉动/拖累

# 业务员页签 — 分析逻辑与价值点

> 版本: v1 | 日期: 2026-07-14 | 业务员数量多(约15人)，故用「聚合KPI + 排行榜 + 散点 + 列表下钻」

## 结构(筛选→聚合KPI→图表→列表下钻)

1. **筛选**: 年份 + 排序(收入/客户数/毛利率) + 搜索
2. **聚合KPI**(不受搜索影响): 业务员人数 / 人均收入 / 人均客户数 / 平均毛利率(收入加权)
3. **收入排行柱状**(Top15，含均值markLine) + **收入vs毛利率散点**(气泡=客户数)
4. **业务员列表 + 下钻**: 点业务员展开「客户构成(R按r.sp聚合，前20) + 月度趋势(R按r.ym聚合)」

## 关键实现与修复
- 后端 sp_customers / sp_gp_margin 由单值改为**按年数组** → 修复此前切年份时表格客户数/毛利率恒显示当前年
- 修复 renderSpBar 的 **avg 未定义 bug**(markLine引用了不存在的变量，导致收入排行图整个不渲染)
- KPI用 getFilteredSPRaw(不含搜索过滤)，避免搜索业务员时整体KPI被误改
- 下钻月度趋势从R按r.ym聚合(无需后端sp_monthly)，金额换算 /1000/10 得万元

## 分析价值
- 人均客户数 → 识别「广撒网」vs「深耕大客户」两类业务员
- 散点右上角=高收入高毛利(明星)，右下角=高收入低毛利(以价换量需警惕)
- 下钻客户构成 → 发现业务员是否过度依赖单一大客户(集中度风险)

# 品牌页签 — 分析逻辑与价值点

> 版本: v1 | 日期: 2026-07-14 | 与品类页签同构(品牌数量少)，聚焦自有品牌 vs OEM 的盈利质量对比

## 结构(筛选→KPI→图表→列表下钻)

1. **年份筛选** brandYearFilter — 联动全部
2. **KPI 卡片**(按选中年份): 各品牌 收入 / 毛利率 / 占比
3. **品牌收入对比柱状**(含同比%) + **品牌收入占比饼图**(<5%隐藏引导线)
4. **品牌月度走势**(Top5折线) + **品牌毛利率对比**(按选中年份)
5. **品牌明细表 + 下钻**: 点品牌展开「产品构成(R按r.brand，前20) + 月度趋势(brandMonthly)」

## 关键实现
- 后端 brand_gp_margin 由单值改为**按年数组**(对齐all_years) → 修复毛利率/毛利率对比图不随年份联动
- 统一 BRAND_COLORS 7色板，各图颜色一致
- 下钻产品构成从R按r.brand聚合(明细行品牌字段 r.brand)

## 分析价值
- 品牌维度核心看**盈利质量**: 自有品牌(十八藏44%/天沏37%)毛利率显著高于OEM/其他(22%)
- 占比饼图 + 同比 → 观察自有品牌培育进度(收入占比是否在提升)
- 下钻产品构成 → 定位品牌旗下爆品/长尾，指导SKU取舍
