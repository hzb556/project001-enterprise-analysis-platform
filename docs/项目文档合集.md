# 第一部分：产品概述

> 面向读者：产品负责人、管理层、新成员入职

## 一、产品定位

**企业运营分析平台** 是一款面向中小企业的 **自助式商业智能（BI）工具**。

**一句话描述**：用户上传 Excel 财务/销售数据 → 系统自动生成包含图表、诊断结论、明细表的完整分析报告。

**核心价值**：把「需要 Excel 高手 + 财务背景 + 一整天时间」的数据分析工作，变成「上传文件 → 3 分钟出报告」。

## 二、目标用户

| 用户角色 | 使用场景 | 核心需求 |
|---------|---------|---------|
| **企业老板/总经理** | 月度经营会议前查看 KPI 仪表盘 | 一眼看清收入趋势、毛利变化、客户流失情况 |
| **财务/销售分析人员** | 月度/季度做分析报告 | 快速生成图表和文字结论，减少手工 Excel 操作 |
| **销售经理** | 管理业务员和客户 | 看业务员排名、客户分层、流失预警 |
| **系统管理员** | 管理用户账号和权限 | 开通/停用账号、分配模块权限 |

## 三、功能模块

### 模块 A：费用分析（企业钱花哪了？花得对不对？）

| 功能 | 说明 |
|------|------|
| KPI 仪表盘 | 总费用、同比/环比变化、科目占比 |
| 趋势图表 | 年度对比柱状图、月度趋势折线图（支持 24 个月智能窗口） |
| 热力图 | 部门×科目交叉分析，一眼看出「哪个部门花哪种钱最多」 |
| 旭日图 | 科目层级结构，支持双向钻取 |
| 异常检测 | 自动标记环比波动 >30% 的异常月份 |
| 诊断结论 | 自动生成结构化文字报告（含建议） |
| 导出 | HTML/Excel/CSV 三种格式 |

### 模块 B：销售分析（收入从哪来？客户买什么？谁在流失？）

**8 个分析视角：**

| 页签 | 回答什么问题 | 核心图表 |
|------|-------------|---------|
| **总览** | 整体收入/毛利/客户情况怎么样？ | KPI卡片 + 年度堆叠柱 + 月度双线 + 双向旭日图 + 诊断结论 |
| **客户** | 谁是核心客户？谁在流失？ | Top10柱状 + 气泡图 + 排名变化 + 帕累托 + 桑基流转 + 明细 |
| **产品** | 哪些产品贡献最大？毛利怎么样？ | Top10柱状 + 气泡图 + 排名变化 + 旭日图 + 生命周期 |
| **品类** | 钛杯/钢杯/塑料杯/配件各占多少？结构在变吗？ | 柱状+饼图 + 月度趋势 + 结构对比 + 明细下钻 |
| **部门** | 营销中心 vs 品牌中心，哪个部门表现好？ | KPI对比 + 月度趋势 + 客户Top10 + 客户占比 + 明细下钻 |
| **业务员** | 15个业务员谁做得好？谁在吃大锅饭？ | 收入排行 + 散点图 + KPI聚合 + 明细下钻 |
| **品牌** | 自有品牌 vs OEM，谁的利润高？ | 柱状+饼图 + 月度趋势 + 毛利率对比 + 明细下钻 |
| **明细** | 我要查具体某笔交易 | 可搜索/筛选/分页/导出的原始数据表 |

**核心分析能力：**
- 客户分层（ABC）：A类（前20%客户）贡献70%收入 → 配专属销售；C类 → 批量维护
- 流失预警：自动识别「沉睡客户」（3个月无交易）和「流失客户」（6个月无交易）
- 新增客户追踪：今年新开发的客户质量如何？有多少进入了沉睡？
- 毛利率监控：哪个品类/产品/客户在「以价换量」？毛利率异常下降？
- 排名变化：客户/产品排名年度变化 ▲▼，快速发现黑马和下滑者

### 模块 C：用户系统

- 邮箱注册/登录
- 套餐分级：免费试用 / 基础版 / 专业版 / 内部全功能
- **RBAC 三级角色**：admin（全部权限）/ manager（查看所有报告）/ user（自己的报告）
- **模块权限**：可控制用户能访问费用分析还是销售分析
- **审计日志**：自动记录 8 种关键操作，敏感信息自动脱敏
- **CSRF 防护**：全局拦截状态修改请求
- **Session 安全**：HttpOnly + SameSite Lax + 8h 有效期
- **强制改密**：生产环境管理员首次登录强制修改密码
- 报告保存：用户的分析结果保存在账号下，可随时回看
- 管理后台：管理员查看所有用户、修改套餐/角色/权限

### 前端
- **无框架**：纯 Vanilla JS，所有图表用 ECharts 5.5

- **蓝图注册**：在 `app.py` 的 `create_app()` 中注册
- **数据缓存**：demo/real 数据使用模块级 `_cache` 变量，首次请求处理（~58k 行），后续直接返回

- `grid.bottom` = 70（有底部图例）/ 50（无图例）
- 禁止 `containLabel: true`
- 饼图 <5%：per-item `label.show=false` + `labelLine.show=false`

### Git
- 单分支（master）
- 每次改动后自动 commit + push
- Commit 格式：`type: 中文描述`

# 第三部分：业务规则

> 定义所有业务计算逻辑、阈值、分类标准。AI 开发和人工验证的统一参考。

## 一、客户状态定义

### 时间窗口

| 概念 | 定义 | 用途 |
|------|------|------|
| **近 3 月** | 数据集中最近的 3 个年月（如 `2025-10 ~ 2025-12`） | 判断活跃/沉睡 |
| **近 6 月** | 数据集中最近的 6 个年月（如 `2025-07 ~ 2025-12`） | 判断流失 |

### 客户状态分类

| 状态 | 判断规则 | 业务含义 |
|------|---------|---------|
| **活跃** | 近 3 个月有交易记录 | 正常客户 |
| **沉睡** | 近 6 个月有交易，但近 3 个月无交易 | 早期预警，挽回成本低 |
| **流失** | 近 6 个月无任何交易记录 | 实质性流失 |

### 新增客户

```
新增客户 = 当年有交易记录 - 上年有交易记录
```

即：去年完全没交易的客户，今年开始交易。

## 二、KPI 计算口径

### 收入相关

| 指标 | 计算公式 |
|------|---------|
| **当期收入** | `SUM(amount) WHERE year = 当前年 AND month ≤ 最新月` |
| **同比收入** | 与上一年相同月份范围对比 |
| **同比增长率** | `(当期收入 / 同期收入 - 1) × 100%`，同期收入=0 时返回 null |
| **CAGR** | `((末年收入 / 首年收入) ^ (1/年数) - 1) × 100%`，至少需要 2 年数据 |

### 毛利相关

| 指标 | 计算公式 |
|------|---------|
| **毛利额** | `SUM(amount) - SUM(cost)` |
| **毛利率** | `(收入 - 成本) / 收入 × 100%`，收入为 0 时返回 0 |
| **毛利率同比** | `当期毛利率 - 上年同期毛利率`（差值，单位：百分点） |

### 客户相关

| 指标 | 计算公式 |
|------|---------|
| **成交客户数** | `COUNT(DISTINCT customer) WHERE year = 当前年` |
| **新增客户数** | 见上文「新增客户」定义 |
| **客单价** | `当期收入 / 当期订单数` |
| **人均收入** | `当期收入 / 当期客户数`（业务员页签用） |

## 三、客户分层（ABC 分析）

| 层级 | 累计客户占比 | 典型收入占比 | 管理策略 |
|------|-------------|-------------|---------|
| **A 级** | 前 20% 客户 | ~70% | 专属销售经理，定期拜访 |
| **B 级** | 20% ~ 50% 客户 | ~25% | 标准维护，季度回访 |
| **C 级** | 后 50% 客户 | ~5% | 批量自动化维护 |

计算步骤：
1. 按收入降序排列所有客户
2. 计算每个客户的累计收入占比
3. 按累计客户数占比分区：≤20% → A，20%~50% → B，>50% → C

## 四、异常检测规则

### 环比异常

| 条件 | 标记 |
|------|------|
| 当月收入环比变化 > +30% | 异常增长（可能是大单或数据错误） |
| 当月收入环比变化 < -30% | 异常下降（可能是客户流失或淡季） |

### 集中度风险

| Top3 客户收入占比 | 风险等级 |
|------------------|---------|
| > 50% | 高风险（高度依赖大客户） |
| 30% ~ 50% | 需关注 |
| < 30% | 健康 |

### IQR 离群值

使用四分位距法：`Q3 + 3 × IQR` 以上的交易被标记为离群值。

## 五、时间范围规则

| 场景 | 规则 |
|------|------|
| 同比计算 | 当年 1 月至最新月份，与上一年同期比较（不是全年比较） |
| 月度趋势图 | 默认显示全部月份（智能窗口 24 个月，超出可滚动） |
| 费用分析窗口 | 默认 24 个月（数据不足时显示全部） |
| 异常检测 | 基于全部可用月份 |
| 年度对比 | 基于数据集中所有年份 |

## 六、数据过滤规则

| 规则 | 处理方式 |
|------|---------|
| 年份不在 2000~2100 | 删除该行 |
| 月份不在 1~12 | 删除该行 |
| 金额为空 | 填充为 0 |
| 客户/产品为空 | 填充为「未知」 |
| 重复记录 | 按 `order_no + year + month + amount` 去重（保留第一条） |
| 负数金额 | 保留（可能是退货） |

### 货币/单位

- 原始数据：人民币元
- 图表显示：万元（÷10000）
- 毛利率：百分比数值（21.9 表示 21.9%）
- 小数精度：收入保留 1 位小数，毛利率保留 1 位小数

## 七、桑基图流转规则

### 节点定义

| 节点 | 含义 |
|------|------|
| 上年活跃 | 上一年度有任何交易记录的客户 |
| 当年新增 | 当年有交易但上年无交易的客户 |
| 当年活跃 | 近 3 个月有交易 |
| 当年沉睡 | 近 6 月有但近 3 月无交易 |
| 当年流失 | 近 6 月无交易 |

### 流转链路

```
上年活跃 → 当年活跃  （留存活跃）
上年活跃 → 当年沉睡  （老客户进入沉睡）
上年活跃 → 当年流失  （老客户流失）
当年新增 → 当年活跃  （新客户活跃）
当年新增 → 当年沉睡  （新客户已沉睡，质量差）
当年新增 → 当年流失  （新客户已流失，质量极差）
```

### 三端同源原则

KPI 卡片 ←→ 桑基图 ←→ 明细表（新增/沉睡/流失列表）必须使用完全相同的定义和计算逻辑。

## 八、毛利率监控规则

| 场景 | 规则 |
|------|------|
| 毛利率同比下降 > 3 个百分点 | 诊断结论中标记为「需关注」 |
| 毛利率同比下降 > 5 个百分点 | 显著下降，建议检查定价策略 |
| 毛利率 < 0 | 亏本销售，需排查是定价错误还是清仓处理 |
| 自有品牌 vs OEM | 自有品牌毛利率应显著高于 OEM（如 40%+ vs 20%） |

- 毛利率：百分比数值（如 21.9 表示 21.9%）
- 数组索引：所有 `*GPMargin`、`*Revenue` 都是按 `all_years` 顺序的数组
- `round()` 永远不要省略（浮点数显示问题）

### 路由规则

- 蓝图前缀：`/sales`（销售）、`/`（费用）
- API 路由：`/api/xxx`
- 所有 API 返回 JSON
- 页面渲染用 `render_template`

### 安全规则

- `SECRET_KEY` 永远不能硬编码（必须从环境变量读）
- `ADMIN_PASSWORD` 生产环境必须是随机生成
- 密码验证必须经过 `validate_password_strength()`
- 路由权限使用 `@require_admin` / `@require_manager` / `@require_module` 装饰器
- 关键操作调用 `audit_log()` 记录审计日志（非阻塞）
- 所有 POST/PUT/DELETE 自动验证 CSRF token（login/register 豁免）

## 九、Git 规则

- **每次代码修改后自动 commit + push**
- Commit message 格式：`type: 中文描述`
  - `feat:` 新功能
  - `fix:` 修复 bug
  - `refactor:` 重构（不改变功能）
  - `style:` 样式调整
  - `docs:` 文档更新
  - `chore:` 杂项（依赖、配置等）
- 永远在 master 分支上开发（单分支策略）

## 十、常见错误速查

| 症状 | 根因 | 解决 |
|------|------|------|
| 图表不显示 | JS 报错（如未定义变量） | 打开浏览器 F12 看 Console |
| 切换年份图表不变 | 年份索引 `yi` 计算出错 | 检查 `indexOf(selY)` 是否返回 -1 |
| 饼图引导线残留 | 只隐藏了 label 没隐藏 labelLine | 用 per-item `labelLine.show` |
| Flask 更新不生效 | `debug=False` 时模板缓存 | 杀掉进程重启 |
| 明细数据对不上 | D 数据和 R 数据口径不一致 | 确保同一数据源（sankey sets） |
| X 轴标签截断 | `bottom` 太小 | 有图例时 bottom=70 |
| 顶部标签截断 | `top` 太小 | top=40 |
| 毛利率年份不联动 | 后端用了单值而非数组 | 改为按 `all_years` 循环计算 |
| API 返回 403 | CSRF token 缺失或无效 | 检查表单含 `_csrf_token` 或 AJAX header `X-CSRF-Token` |
| admin API 返回 403 | 用户 role 不是 `admin` | 检查数据库 `users.role` 字段 |
| 生产环境拒绝启动 | SECRET_KEY 未设置/太短 | 生成 32 位随机密钥设置到环境变量 |
